# Новости Spike Launcher

Редактируйте `news.json` в ветке `main`. Лаунчер проверяет ленту при каждом запуске и сохраняет последнюю успешно загруженную версию.

- `schema` — версия формата, сейчас `1`.
- `posts` — список постов в порядке отображения.
- `id`, `badge`, `title` и `summary` — постоянный ID, метка, заголовок и вступление.
- `featured: true` — вывести большой баннер на главной и вверху новостей. Можно отметить несколько постов.
- `banners` — список прямых HTTPS-ссылок на JPEG или PNG. Первое изображение используется как обложка, в статье показываются все.
- `body` — список блоков с `text` и необязательным `title`. Двойной перенос строки разделяет абзацы.
- `links` — список кликабельных ссылок с полями `label` и `url` (HTTPS).
- `cardSummary`, `byline` и `showBodyOnCard` — необязательные анонс, подпись автора и вывод текста прямо в карточке.

Изображения можно хранить в `banners/` и указывать прямые ссылки вида `https://raw.githubusercontent.com/spikelauncher/news/main/banners/имя.jpg`. Для замены картинки лучше дать ей новое имя, чтобы обновить кэш.
